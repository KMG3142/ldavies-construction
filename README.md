## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, e.g. `ldavies-construction`.
3. Upload everything inside this folder to the repository.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a temporary `github.io` web address.

## Connect the Wix-bought domain
Do this only after the GitHub Pages site is live.

1. In the GitHub repository go to **Settings → Pages → Custom domain**.
2. Enter your domain.
3. In Wix, open the domain's DNS records and point them to the values GitHub gives/recommends.
4. Once DNS has propagated, enable **Enforce HTTPS** in GitHub Pages.

Important: keep the domain registered with Wix. You are only changing where the domain points.
